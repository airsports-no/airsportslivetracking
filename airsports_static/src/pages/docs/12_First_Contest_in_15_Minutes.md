# Your First Contest in 15 Minutes

This walkthrough takes you from a new account to a working practice contest with one route, one task and one test pilot. New to the vocabulary? Read [How ASLT Works](/docs/00_How_ASLT_Works) first.

> **Tip:** Do this once as a private "Test Competition" before your real event. Contests are private until you change the visibility, so nobody else will see it.

---

## 1. Become an organizer (1 minute)

Create an account at **app.airsports.no** and click **Become an Organizer** in the top bar. It is instant. A **Management** menu appears.

## 2. Create the contest (2 minutes)

1. **Management → My contests → Create New Contest.**
2. Fill in a name, the time zone, the start and finish dates and the location (click the map).
3. Leave the *Advanced* section alone for now and press **Submit**.

You land on the contest page. A **setup checklist** at the top tracks what is left to do.

## 3. Draw a route (5 minutes)

1. **Management → Route editor → Create new route**, or **Import route** if you already have a file (KML, KMZ, GPX or CSV).
2. Add the start point, the turning points and the finish. The editor's help button explains each element.
3. **Save.** A message offers **Create navigation task**. Use it, or skip ahead to step 4.

A route is reusable. You can build tasks in many contests from the same route.

## 4. Create the navigation task (3 minutes)

1. On the contest page press **Add navigation task** (or use the offer after saving the route).
2. Choose the **task type**, then the **route**. If no route fits you can create one in a new tab and press *Refresh routes*.
3. Fill in the details. Hover the info icons for what each field means. The scorecard is preselected and can be changed later.
4. Press **Create navigation task**.

## 5. Add a test team and schedule it (3 minutes)

1. Back on the contest page use **Add team** under *Registered teams*: you as pilot, any aircraft registration.
2. On the task page use **Quick Add** to put the team on the task. For many teams use **Scheduling** instead.

## 6. Try it (1 minute)

Open the task's **Live Map**. To test scoring without flying, upload a GPX file as a track for your test contestant (see [Route Creation and Tasks](/docs/04_Route_Creation_and_Tasks)).

---

## Ready for the real event?

- **Visibility:** open *Contest settings → Publicity* and choose Public or Unlisted. If you want pilots to register themselves, also tick *Allow self-management* on the task and set the task visibility to **Public**. The task card warns you when pilots cannot see it yet.
- **Flight orders:** generate and send them from the task's **Manage** menu once start times are set.
- **Pilots need the app,** logged in with the same email they are registered with.
- Details: [Contest Manager Guide](/docs/03_Contest_Manager_Guide).
