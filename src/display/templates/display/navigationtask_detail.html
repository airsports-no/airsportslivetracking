Adding Contestants

For single contestants these can be added using the Quick add button for the contestant to be created with useful default values from the team registration. Edit the contestant by clicking its name after creation to change any of the default settings.

For a competition with more than a few contestants we recommend using the Scheduling assistant (under More Tools) to create a conflict free time schedule.

If conditions change during the event, use Batch Update Contestants to easily update wind speed and direction for multiple contestants at once, or shift the entire contest timeline for all remaining future contestants by a set number of minutes.
